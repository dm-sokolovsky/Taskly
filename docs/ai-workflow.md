# Журнал работы с AI

## Правила фиксации

Основной агент обновляет этот файл после каждого завершённого этапа. Записываем существенные решения и проверяемые факты, без полной переписки, секретов и внутренних рассуждений моделей.

Для каждого этапа фиксируем: задачу, исполнителя и инструмент, результат, проверки, принятые решения и оставшуюся работу. Сначала запись имеет статус «запланировано» или «в работе»; «выполнено» ставим только после получения результата.

Различаем проверки агента и самостоятельные проверки Дмитрия. Самостоятельную проверку фиксируем только после его сообщения с результатом. Агент документации собирает README из этого журнала и сверяет его с кодом; отсутствие подтверждения отмечает как пробел.

Ревью отдельным агентом запланировано на контрольную точку после реализации. Агент документации запланирован для финальной сверки README. До их фактического запуска не указываем их участие как выполненную работу.

- Обновлены README, спецификация и AGENTS.md в соответствии с текущим состоянием.
- Новые зависимости не добавлялись. Код не публиковался; коммит этого этапа не выполнялся.

### Решения

- Состояние типизировано; текст задач выводится через JSX без вставки HTML.
- Ключ хранилища: `taskly.tasks.v1`. Чтение выполняется при инициализации с проверкой структуры и уникальности идентификаторов. Новые задачи получают `crypto.randomUUID()`.
- Сохранение выполняется в обработчиках добавления, переключения и удаления. Запись не происходит при открытии страницы: некорректные исходные данные сохраняются до первого изменения пользователем.
- При ошибке записи изменения остаются в памяти, пользователь видит предупреждение. При следующем успешном сохранении предупреждение снимается.
- При удалении фокус переходит к соседней задаче, при удалении последней — в поле добавления.
- Предварительная оптимизация и дополнительные библиотеки для небольшого списка не потребовались.

### Проверки агента

- `npm run build` — успешно: TypeScript и production-сборка.
- Первый `npm run lint` выявил синхронное обновление состояния в эффекте при обработке ошибки записи. Сохранение перенесено в обработчики действий, правило ESLint сохранено. Повторные lint и build прошли.
- Браузер: headless Chromium из установленного Playwright, macOS, размеры 1280 × 1000 и 375 × 900. Dev-сервер и браузер потребовали разрешения sandbox на запуск.
- Временный проверочный скрипт: `/private/tmp/taskly-check.mjs`, запуск `node /private/tmp/taskly-check.mjs`. Использован Playwright из существующего npm-кэша; путь локален и не является настройкой проекта. Скрипт не входит в репозиторий и не заменяет воспроизводимый тестовый набор.
- Успешно пройдены 9 групп проверок: F1/F2, F3/F5, F4/F5 с восстановлением фокуса, U1, S1, U2, S2, S3, Q3. Проверены добавление кнопкой и Enter, пустой ввод, изолированное переключение и отмена, удаление выбранной и последней задачи, сохранение после обновления для всех действий.
- Клавиатура: добавление, переключение Space, удаление Enter; проверены порядок Tab, восстановление фокуса и наличие outline у чекбокса. Первый прогон остановился из-за ошибочного ожидания двух Tab после добавления: отключённая кнопка пропускается. Исправлено ожидание скрипта, затем все группы прошли.
- Безопасность хранения/вывода: HTML-строка отображается текстом после обновления; некорректный JSON, неправильные типы и повторяющиеся ID не обрушивают интерфейс; отказ `Storage.setItem` показывает предупреждение, последующая успешная запись восстанавливает сохранение.
- На ширинах 375 и 1280 px длинная строка без пробелов не вызывает горизонтального переполнения; кнопка удаления остаётся в пределах экрана.
- На 100 задачах последовательность «добавить → переключить → удалить» заняла около 146 мс, включая накладные расходы автоматизации. Это наблюдение одного прогона, не benchmark и не гарантия для других устройств.
- Ошибок `pageerror` в успешном прогоне не обнаружено. Снимки списка для desktop/mobile просмотрены основным агентом; снимки находятся в `/private/tmp/taskly-list-desktop.png` и `/private/tmp/taskly-list-mobile.png`, пустое состояние — `/private/tmp/taskly-empty-desktop.png`.
