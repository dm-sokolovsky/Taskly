## Зависимости

- Исходный `npm audit --json`: 13 затронутых пакетов, включая один high и 12 moderate.
- После обновления Vite: `npm audit --json --fetch-retries=0 --fetch-timeout=20000` завершился с кодом 1, остаются 12 moderate в dev-зависимостях цепочки ESLint. Это незакрытый результат, а не успешный полный аудит.
- `npm audit --omit=dev --json --fetch-retries=0 --fetch-timeout=20000`: код 0, известных уязвимостей production-зависимостей не найдено на момент проверки.
- Оставшиеся 12 записей связаны с одним advisory `minimatch` и его потребителями, это не 12 независимых первопричин. Риск — отказ в обслуживании при обработке специально подобранных glob-шаблонов.
- Реестр сообщил для последнего ESLint 10.14.0 зависимость `minimatch ^10.2.6`; advisory охватывает версии `<11.0.1`. Обновление ESLint само по себе не даёт подтверждённого исправления. Установленные потребители используют разные major-версии minimatch; принудительный override до 11 не применялся без подтверждения совместимости. Автоматический `audit fix --force`, предлагающий downgrade typescript-eslint до 8.14.0, также не применялся.
- В текущем проекте ESLint запускается локально с конфигурацией репозитория, пользовательский текст задач не передаётся в glob-шаблоны. Из этого следует ограниченная применимость данной уязвимости к работающему сайту; это не устраняет уязвимость инструмента. Перед сдачей/обновлением зависимостей повторить audit и проверить исправления upstream.

Источники: [minimatch advisory](https://github.com/advisories/GHSA-g3hv-75wg-m249), [Vite: доступ к файлам вне разрешённой области](https://github.com/advisories/GHSA-rq7h-c2jc-7f22), [launch-editor: выполнение команд на Windows](https://github.com/advisories/GHSA-587h-7wmj-h5pm). Контраст: [W3C Understanding SC 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).

## Ограничения

- Сравнение `getItem` перед `setItem` предотвращает воспроизведённое последовательное затирание. Эти операции не атомарны между вкладками: одновременные записи всё ещё могут конфликтовать. Полноценная синхронизация вкладок не реализована; рекомендуется работать с одним списком в одной вкладке.
- При конфликте или неизвестном исходном списке несохранённые изменения остаются только в памяти. Предупреждение предлагает скопировать нужные задачи перед обновлением.
- Не проверялись Safari, screen reader, реальные мобильные устройства и опубликованный хостинг. Рассчитанный контраст не означает полный аудит доступности.
- Самостоятельная проверка Дмитрием в журнале подтверждена для отображения ошибки повреждённых данных; остальные сценарии требуют подтверждения результата.
