# Taskly

Тестовое задание для вакансии начинающего разработчика с AI-инструментами: простой список задач на React, TypeScript и Vite.

Цель — реализовать добавление, отметку выполнения и удаление задач с сохранением после обновления страницы, а также показать проверяемый процесс работы с AI.

## Состояние проекта

Подготовлен стартовый шаблон. Функциональность списка задач пока не реализована; рабочий сайт ещё не опубликован.

- [Задание, критерии готовности и план проверок](docs/task.md)
- [Журнал работы с AI и текущее состояние](docs/ai-workflow.md)

## Запуск

```bash
npm ci
npm run dev
```

## Проверки и сборка

```bash
npm run lint
npm run build
npm run preview
```

Build проверяет TypeScript и создаёт сборку; lint проверяет код. Проверка пользовательских сценариев выполняется отдельно. Результаты записываются в журнал работы.

## Использование AI

На этапе подготовки использован Codex: обзор репозитория, обсуждение процесса разработки и подготовка документации по заданию. Дмитрий предоставил условия тестового и добавил требования к проверке безопасности и качества кода.

Реализация, ревью отдельным агентом, проверки приложения и самостоятельная проверка Дмитрием ещё не выполнены. По мере работы этот раздел будет дополнен подтверждёнными результатами.
