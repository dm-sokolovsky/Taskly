# Taskly

Тестовое задание для вакансии начинающего разработчика с AI-инструментами: простой список задач на React, TypeScript и Vite.

Цель — реализовать добавление, отметку выполнения и удаление задач с сохранением после обновления страницы, а также показать проверяемый процесс работы с AI.

## Состояние проекта

Реализован первый вариант: светлый адаптивный интерфейс, добавление задач кнопкой или Enter, отметка выполнения, удаление и сохранение в `localStorage`. Счётчики показывают оставшиеся и выполненные задачи. Сайт размещается на GitHub Pages; настройка публикации описана ниже.

Кнопка «Удалить все задачи» появляется при непустом списке. Удаление выполняется после подтверждения предупреждения браузера; отмена сохраняет список. После удаления пустой список сохраняется в браузере.

Список хранится только в текущем браузере и не синхронизируется между устройствами. При ошибке чтения приложение различает повреждённые данные и недоступное хранилище. При ошибке записи объясняет риск потери изменений после обновления или закрытия страницы; после успешного сохранения предупреждение исчезает. Хранилище не предназначено для конфиденциальных данных.

## Проверки и сборка

```bash
npm run lint
npm run build
npm run preview
```

Build проверяет TypeScript и создаёт сборку; lint проверяет код. Проверка пользовательских сценариев выполняется отдельно. Результаты записываются в журнал работы.

Для первого варианта успешно выполнены build и lint. В Chromium через Playwright проверены четыре обязательные функции, клавиатура, длинный текст на ширинах 375 и 1280 px, отображение HTML как текста, некорректные данные и отказ записи в хранилище, работа со 100 задачами. Автоматизированные проверки выполнялись временным скриптом через уже установленный Playwright; воспроизводимого тестового набора и команды `npm test` в репозитории пока нет.

Отдельное ревью выполнено: исправлены защита от перезаписи данных в устаревшей вкладке и после ошибки чтения, контраст рабочего текста. Production-сборка проверена в Chromium. Vite обновлён до 8.3.5; аудит production-зависимостей не нашёл известных уязвимостей. Повторный аудит от 2026-11-10 показал 7 moderate в dev-цепочке typescript-eslint/minimatch и 0 уязвимостей в production; причины и ограничения описаны в отчёте ревью. Другие браузеры не проверялись.

Для работы со списком используйте одну вкладку: обнаруженные изменения другой вкладки блокируют сохранение с предупреждением, но атомарной синхронизации одновременных записей нет.

## Использование AI

Использован Codex: обзор репозитория, обсуждение процесса, документация, реализация интерфейса и логики задач, запуск build и lint, проверки в Chromium через Playwright. Дмитрий предоставил условия тестового, добавил требования к проверке безопасности и качества кода и выбрал светлое визуальное направление.

Отдельный агент Codex выполнил ревью и повторную проверку исправлений. Два отдельных агента повторили аудит зависимостей и сверили устаревшую запись о коммитах в отчёте; основной агент актуализировал документацию. Дмитрий подтвердил самостоятельную проверку кода. Результаты самостоятельной проверки Дмитрия отражены в журнале.

## Публикация на GitHub Pages

Для репозитория `dm-sokolovsky/Taskly` в Vite установлен `base: '/Taskly/'`.
В GitHub откройте Settings → Pages → Build and deployment → Source и выберите **GitHub Actions**.
После отправки изменений в `main` workflow `.github/workflows/deploy.yml` установит зависимости, выполнит lint и build и опубликует содержимое `dist`.
Дождитесь успешного workflow **Deploy to GitHub Pages** во вкладке Actions.

Адрес: https://dm-sokolovsky.github.io/Taskly/. Публиковать исходный `index.html` из корня ветки нельзя: он ссылается на TypeScript, который должен обработать Vite.
При переименовании репозитория или подключении собственного домена нужно актуализировать `base`.
